# AWTRIX NG Control v1.1.3

## English

### Advanced notification improvements
- Native Home Assistant device targeting for advanced notifications.
- TC002 notifications with separate title and message lines, using a compact layout.
- Support for notification icons, text colors, sounds, duration, and other existing advanced options.
- Existing service calls and integrations remain available.

### Testing
The advanced notification flow was tested successfully on a Ulanzi TC002, including device targeting, title/message layout, icon, text color, sound, and duration. Other device-management and restore operations have not all been validated on hardware.

### Installation
Install or update via HACS (custom repository: https://github.com/LinusIta/AWTRIX-NG-Control), then restart Home Assistant.

## Italiano

### Miglioramenti notifiche avanzate
- Selezione nativa del dispositivo Home Assistant per le notifiche avanzate.
- Titolo e messaggio su due righe per il TC002, con layout compatto.
- Supporto per icone, colore del testo, suoni e durata.
- Compatibilità mantenuta con i servizi già esistenti.

### Collaudo
Il flusso delle notifiche avanzate è stato verificato sul TC002: selezione dispositivo, layout, icona, colore, suono e durata. Le altre funzioni amministrative e di ripristino non sono state tutte collaudate sul dispositivo.
